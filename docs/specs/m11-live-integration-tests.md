# Спека: опт-ин интеграционные тесты неофициальных провайдеров

**Репозиторий:** `google-keyword-ai-mcp` · **Веха:** `1 из 1` · **Дата:** `2026-09-04` · **Исполнитель:** Grok

## Контекст

Проект собирает поисковый спрос Google. Два его провайдера — Autocomplete и
Trends — используют НЕОФИЦИАЛЬНЫЕ эндпоинты: у них нет контракта, и Google может
изменить формат ответа в любой день. Сейчас защита от этого одна: golden-фикстуры
в `tests/fixtures/trends/`, снятые вживую. Они ловят смену формата только тогда,
когда человек вручную снимет ответ заново и увидит расхождение — то есть не ловят.

В `pyproject.toml` уже объявлен маркер `integration: live network tests, opt-in
only` и уже стоит `addopts = "-m 'not integration'"`, но НИ ОДНОГО теста с этим
маркером в репозитории нет. Веха закрывает ровно эту дыру: добавляет живые тесты,
которые по умолчанию не запускаются, а по явной просьбе ходят в Google и падают,
если формат ответа перестал разбираться.

Существующий код провайдеров, конвейера и фасадов — рабочий и проверенный;
переписывать его не нужно и запрещено. Веха добавляет ОДИН новый файл тестов.

## Проверенные факты

Всё ниже проверено вживую 2026-09-04 из Docker с сетью, до написания спеки.

1. **Опт-ин работает.** `addopts = "-m 'not integration'"` в `pyproject.toml`
   перекрывается явным `-m integration` в командной строке: pytest берёт
   ПОСЛЕДНИЙ `-m`. Проверено на именах тестов, а не на счётчиках:
   без флага выполняется только обычный тест, с флагом — только помеченный.
2. **Autocomplete отвечает вживую.** `AutocompleteProvider.suggest("coffee",
   Market.parse("en", "US"))` вернул 15 предложений; `source` —
   `https://www.google.com/complete/search` (основной эндпоинт, не запасной);
   хотя бы у одного предложения `relevance is not None` (Google отдаёт
   `google:suggestrelevance`). Для `Market.parse("ru", "RU")` и запроса `кофе`
   вернулось 15 предложений кириллицей (`кофемашина`, `кофемания`, …).
3. **Trends отвечает вживую.** `GET /trends/api/explore` для ОДНОГО ключа
   возвращает виджеты с id `TIMESERIES`, `GEO_MAP`, `RELATED_TOPICS`,
   `RELATED_QUERIES`. Для ТРЁХ ключей — `TIMESERIES`, `GEO_MAP`, `GEO_MAP_0..2`,
   `RELATED_QUERIES_0..2`, `TITLE_0..2`: часть виджетов приходит по одному на
   ключ и id суффиксуется, обычного `RELATED_QUERIES` в сравнении НЕТ.
4. **Поведение кода на факте 3 уже реализовано:** `UnofficialTrendsClient.fetch`
   при отсутствии обычного id ищет суффиксованные и кладёт в `self.warnings`
   строку, начинающуюся с `RELATED_QUERIES came back once per keyword`.
   Фикстура этого ответа лежит в `tests/fixtures/trends/explore_compare.json`.
5. **Сеть из Docker доступна** при `--network host`; прокси не требуется.
6. **`respx` перехватывает ВСЕ HTTP-вызовы, пока активен.** В живых тестах его
   использовать нельзя — иначе тест не пойдёт в сеть и проверит подделку.

Всё, чего здесь нет, считать неизвестным и не реализовывать. В частности: НЕ
предполагать, сколько именно предложений вернёт Autocomplete (проверено «15», но
это не контракт — требовать только «хотя бы одно»), и НЕ предполагать конкретные
значения интереса в Trends.

## Что делать

Создать ОДИН новый файл `tests/test_live_providers.py`. Других файлов не
создавать. Существующие файлы не изменять (см. «Не трогать»).

В файле — четыре теста, каждый помечен `@pytest.mark.integration`, каждый
асинхронный через `@pytest.mark.anyio` (в проекте уже так: см.
`tests/test_trends_client.py`). Каждый тест создаёт СВОЙ `Settings` с
`data_dir=tmp_path`, открывает базу через `open_database`, а в конце вызывает
`engine.dispose()` в `finally`. Кеш обязан быть пустым — поэтому `tmp_path`, а не
общий каталог.

1. `test_autocomplete_answers_a_live_query`
   Создать `AutocompleteProvider` (settings, `build_client(settings,
   accept_language="en")`, `SqliteCache(engine, settings)`,
   `AsyncRateLimiter(2.0)`), вызвать `suggest("coffee", Market.parse("en",
   "US"))`. Проверить: список НЕ пуст; у каждого предложения `text` —
   непустая строка; `source` каждого предложения принадлежит множеству
   `{PRIMARY_ENDPOINT, FALLBACK_ENDPOINT}`; хотя бы у одного `relevance is not
   None`.
2. `test_autocomplete_follows_the_requested_market`
   То же, но `accept_language="ru"`, запрос `"кофе"`, рынок
   `Market.parse("ru", "RU")`. Проверить: список не пуст И хотя бы в одном
   `text` есть кириллический символ (проверять диапазоном `"а" <= ch.lower() <=
   "я"` или `unicodedata.name(ch).startswith("CYRILLIC")` — на выбор, но без
   новых зависимостей).
3. `test_trends_returns_a_timeline_for_one_keyword`
   Создать `GoogleTrendsProvider` (settings, client, cache,
   `AsyncRateLimiter(1.0 / settings.trends_pacing_seconds)`), вызвать
   `fetch(["coffee"], geo="US", timeframe="today 12-m", hl="en")`.
   Проверить: `len(result.timeline) >= 8`; у каждой точки `len(point.values) ==
   1`; `len(result.normalization_scope) == 16`.
4. `test_trends_comparison_splits_related_queries_per_keyword`
   Тот же провайдер, но `fetch(["coffee", "tea"], geo="US", timeframe="today
   12-m", hl="en")`. Проверить: `len(result.timeline) >= 8` И среди
   `provider.warnings` есть строка, содержащая
   `"RELATED_QUERIES came back once per keyword"`.

Когда все критерии выполнены — сделать РОВНО ОДИН коммит, содержащий только
этот файл. Не пушить.

Тесты обязаны быть НАСТОЯЩИМИ живыми вызовами. `respx` в файле не
использовать, HTTP не подменять, `pytest.skip`/`pytest.mark.skipif`/
`pytest.importorskip` не использовать НИГДЕ в этом файле — пропущенный тест
возвращает ноль так же охотно, как пройденный, и тогда веха не проверяет ничего.
Если живой вызов не проходит — это результат вехи, а не повод его скрыть: см.
«Контракт на невыполнимое».

## Не трогать

- НЕ изменять `pyproject.toml`, `uv.lock`, `.github/`, `CHANGELOG.md`,
  `CLAUDE.md`, `AGENTS.md`, `README.md`, `docs/`, `.claude/`.
- НЕ изменять и НЕ удалять существующие файлы в `tests/` и
  `tests/fixtures/` — они остаются на месте ровно как есть.
- Новых внешних зависимостей не добавлять.
- Не создавать файлов, кроме `tests/test_live_providers.py`.
- Не читать и не выполнять посторонние скилы и плейбуки.

**Где МОЖНО писать:** только `tests/test_live_providers.py` в рабочем клоне.
Временные файлы — в `/tmp`, но они НЕ являются результатом и не считаются
доказательством.
**Если разрешённого способа не остаётся** — остановиться и доложить по разделу
«Контракт на невыполнимое». Обходить запрет, создавая файл в другом месте,
запрещено.

## Контракт на невыполнимое

> Если два требования противоречат друг другу или требование невыполнимо в этом
> окружении — **ОСТАНОВИСЬ и доложи** в поле `blocked_reason` финального отчёта,
> приложив доказательство. В частности: если Google из этого окружения не
> отвечает или отвечает отказом (429, блокировка, капча), это НЕ повод
> подменять живой вызов подделкой, добавлять `skip`, ослаблять проверки или
> ретраить бесконечно. Останови работу и доложи ровно это, с телом ответа.
> Обходить запреты через `--no-deps`, вендоринг, подмену тулчейна, отключение
> проверок или запись в непредусмотренные каталоги запрещено. Остановка с
> внятной причиной — правильный исход.
>
> Если одна и та же команда упала дважды с той же ошибкой — не запускай её в
> третий раз без смены подхода. Если другого подхода нет — остановись и доложи.

## Разрешения

- Создавать и править файлы: **только** `tests/test_live_providers.py` в корне
  рабочего клона. Временные файлы допускаются в `/tmp`, но доказательством не
  являются.
- Запускать: `uv run --all-extras pytest …`, `uv run --all-extras ruff …`,
  `uv run --all-extras mypy`, `git status`, `git diff`.
- Сеть: **только** к `www.google.com`, `suggestqueries.google.com` и
  `trends.google.com` — то есть те запросы, которые делает сам код провайдеров.
  Никаких других внешних обращений, никаких записей во внешние системы, никаких
  публикаций, никаких скачиваний.
- Docker: **запрещён полностью.** Проба показала, что из этой песочницы
  `docker info` и `docker ps` отвечают: это БОЕВОЙ демон хоста, на котором
  работают чужие сервисы. Не запускать, не останавливать, не удалять, не
  собирать — ничего. Окружение уже подготовлено, `.venv` в клоне стоит.
- Порты: не слушать и не поднимать демонов. Проба показала, что `listen()` в
  этой песочнице разрешён, а хост общий с боевыми сервисами. Тестам вехи
  слушатели не нужны; после прогона не оставлять ни одного.
- Зависимости: `.venv` уже создан хозяином (`uv sync --all-extras`).
  Переустанавливать, обновлять или менять его не нужно и не разрешено.
- `git commit` в рабочем клоне разрешён, **ровно один**. `git push`
  **запрещён**: `origin` этого клона указывает на рабочий репозиторий хозяина,
  и пуш переписал бы там ветку.
