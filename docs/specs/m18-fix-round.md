## Дыра 1 — «первый пригодный пакет» нигде не проверен

`combine` обещает в докстроке: якорь выпускается один раз, с покрытием ПЕРВОГО
пригодного пакета. Код это делает, тесты — нет. Проверено: замена
`elif anchor_row.relative_demand is None and row.relative_demand is not None:`
на `elif True:` (якорь всегда перезаписывается последним пакетом) оставляет
набор зелёным.

Добавить два теста в `tests/test_demand.py`:

- успех + успех, у пакетов РАЗНОЕ число целых недель: у выпущенного якоря
  `batch == 1` и `weeks` первого пакета;
- успех + поздний упавший пакет: якорь остаётся числом из первого пакета, а
  участник упавшего едет `None` с дословной причиной провайдера.

## Дыра 2 — три оговорки сверяются только по длине

Единственная проверка — `len(result.data.caveats) == 3`, поэтому инверсия текста
`RELATIVE_CAVEAT` на «Values are absolute search volumes.» набор не роняет.

Сверять дословно, импортом констант:
`assert result.data.caveats == [RELATIVE_CAVEAT, RESOLUTION_CAVEAT, STITCHING_CAVEAT]`.

## Дыра 3 — дефолт окна `today 12-m` не читает ни один тест

Явный `today 3-m` проверяется, дефолт — нет: подмена дефолта на `today 5-y`
оставляет набор зелёным. Дефолт продублирован в usecase, CLI и MCP, и ни один
из трёх не прибит тестом.

Проверить в тесте, который не передаёт `timeframe`: и `data.timeframe`, и то,
что реально ушло в запрос — `comparisonItem[0]["time"]`.

## Дыра 4 — нет алгоритмического успеха ровно на двух ключах

Нижняя граница держится только отказными случаями. Добавить прямую проверку:
`assert plan_batches(["a", "b"], "a") == [["a", "b"]]`.

## Обязательное закрепление: три мутации в обвязку

Чтобы дыры не открылись снова, добавить в `tests/mutation_gate_demand.py` три
мутации к существующим семи, по тем же правилам (одна правка на мутанта, свой
целевой тест, своя дословная строка ассерта, откат с проверкой sha256):

- якорь всегда перезаписывается поздним пакетом (`elif True:`);
- текст `RELATIVE_CAVEAT` заменён на «Values are absolute search volumes.»;
- дефолт `timeframe` в `usecases/demand.py` заменён на `today 5-y`.

После правок `.venv/bin/python tests/mutation_gate_demand.py` обязан убить все
десять, а `--self-check` — оставаться честным.

несовместимость; глушить код возврата; прятать падение под `pytest.skip`.
