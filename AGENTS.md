# AGENTS.md — правила для агентов в этом репозитории

## Границы этого прогона

- Источник требований — файл спеки из промпта
  (`docs/specs/m11-live-integration-tests.md`). Он имеет приоритет над
  глобальными соглашениями.
- Git: ровно один коммит разрешён; `push` запрещён; ветку
  `m11-live-integration-tests` не переключать и не ребейзить.
- Не создавать файлов, которых нет в разделе «Что делать» спеки. В этой вехе
  разрешён ровно один новый файл: `tests/test_live_providers.py`.
- Не загружать посторонние скилы и плейбуки, если спека этого не требует.

## Команды

- Установка зависимостей: не требуется — `.venv` уже создан хозяином
  (`uv sync --all-extras`). Не переустанавливать и не обновлять.
- Сборка: не требуется, это библиотека и набор тестов.
- Тесты: `uv run --all-extras pytest -q` (живые: `uv run --all-extras pytest -m integration -q`)
- Линтер / типы: `uv run --all-extras ruff check . && uv run --all-extras ruff format --check . && uv run --all-extras mypy`

У Grok есть сеть и доступ к Docker. Это техническая возможность, а не
разрешение на внешние изменения: действуют только границы спеки и запреты ниже.

## Чего делать нельзя

- Нельзя обращаться с записью к боевым сервисам и эндпоинтам. Из сети разрешено
  ЧИТАТЬ только `www.google.com`, `suggestqueries.google.com` и
  `trends.google.com` — те же адреса, куда ходит код провайдеров.
- Docker запрещён полностью: демон на этом хосте боевой и обслуживает чужие
  сервисы. Не запускать, не останавливать, не удалять, не собирать образы.
- Нельзя слушать порты и оставлять после себя демонов: хост общий.
- Нельзя трогать чужие контейнеры, сети, тома и образы.
- Запрещено выполнять git push, менять ветку или делать rebase.
- Нельзя обходить несовместимость зависимостей (`--no-deps`,
  `--force-reinstall`, вендоринг, подмена тулчейна, отключение проверок).
- Нельзя повторять ту же упавшую команду третий раз без смены подхода.
- Нельзя добавлять секреты, токены и ключи в репозиторий или вывод команд.
- Нельзя прятать падение живого вызова под `pytest.skip`, `skipif`,
  `importorskip` или подделкой HTTP (`respx`). Не отвечает Google — это
  результат, о котором надо доложить, а не скрыть.

## Карта репозитория

- `src/google_keyword_ai/providers/` — провайдеры: `autocomplete.py`,
  `google_ads.py`, `search_console.py`, `trends/` (неофициальный клиент
  `unofficial.py` и фасад `provider.py`). В этой вехе НЕ изменяются.
- `src/google_keyword_ai/{config,market,http,cache,ratelimit}.py` — настройки,
  рынок (`Market.parse`), HTTP-клиент с ретраями, SQLite-кеш, троттлеры.
- `src/google_keyword_ai/storage/engine.py` — `open_database(settings)`.
- `tests/` — существующие тесты; используют `respx` для подделки HTTP.
  Все они остаются на месте и не изменяются.
- `tests/fixtures/trends/` — боевые golden-ответы Google Trends. Не трогать.
- `docs/specs/` — спеки вех, включая спеку этого прогона.
- `pyproject.toml` — маркер `integration` и `addopts = "-m 'not integration'"`
  уже объявлены; изменять файл не нужно.
