# AGENTS.md — правила для агентов в этом репозитории

## Границы этого прогона

- Источник требований — файл спеки из промпта
  (`docs/specs/m12-concurrent-migrations.md`). Он имеет приоритет над
  глобальными соглашениями.
- Git: ровно один коммит разрешён; `push` запрещён; ветку
  `m12-concurrent-migrations` не переключать и не ребейзить.
- Не создавать файлов, которых нет в разделе «Что делать» спеки. В этой вехе
  изменяются ровно два существующих файла:
  `src/google_keyword_ai/storage/migrations.py` и `tests/test_migrations.py`.
- Не загружать посторонние скилы и плейбуки, если спека этого не требует.

## Команды

- Установка зависимостей: не требуется и НЕВОЗМОЖНА — сети нет. `.venv` уже
  создан хозяином (`uv sync --all-extras`). Не переустанавливать, не обновлять,
  не трогать `pyproject.toml` и `uv.lock`.
- Сборка: не требуется, это библиотека и набор тестов.
- Тесты: `uv run --all-extras pytest -q`
- Линтер / типы: `uv run --all-extras ruff check . && uv run --all-extras ruff format --check . && uv run --all-extras mypy`

## Чего делать нельзя

- Сети нет. Ничего не скачивать и не пытаться — команда просто упадёт.
- Docker не использовать: из этой песочницы он недоступен, и веха в нём не
  нуждается. Команда с `docker` в проверке не выполнится, а её отсутствие в
  логе выглядит как несделанная работа.
- Нельзя трогать чужие контейнеры, сети, тома и образы.
- Запрещено выполнять git push, менять ветку или делать rebase.
- Нельзя обходить несовместимость зависимостей (`--no-deps`,
  `--force-reinstall`, вендоринг, подмена тулчейна, отключение проверок).
- Нельзя повторять ту же упавшую команду третий раз без смены подхода.
- Нельзя добавлять секреты, токены и ключи в репозиторий или вывод команд.
- Нельзя прятать гонку ретраями в тесте, `skip`, `xfail`, абсурдным
  `busy_timeout` или сериализацией через внешний файл-замок. Не сходится —
  остановись и доложи в `blocked_reason`.

## Карта репозитория

- `src/google_keyword_ai/storage/migrations.py` — forward-only миграции через
  `PRAGMA user_version`; `SCHEMA_VERSION = 3`, тела `_migration_1..3`,
  список `MIGRATIONS`, функция `apply_migrations(engine)`. ЭТО файл вехи.
- `src/google_keyword_ai/storage/engine.py` — `create_engine_for`,
  `open_database`, PRAGMA (`journal_mode=WAL`, `busy_timeout=5000`,
  `synchronous=NORMAL`, `foreign_keys=ON`). НЕ изменять.
- `src/google_keyword_ai/errors.py` — иерархия `GkaiError`, в том числе
  `InvalidConfigurationError`. НЕ изменять, только импортировать.
- `tests/test_migrations.py` — существующие тесты миграций. ЭТО второй файл
  вехи: к нему ДОБАВЛЯЕТСЯ тест, существующие не переписываются.
- `tests/test_storage.py` — тесты движка и PRAGMA. НЕ изменять.
- Остальной `src/` и `tests/` к вехе отношения не имеют и не изменяются.
